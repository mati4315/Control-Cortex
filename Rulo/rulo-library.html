Comportamiento automático

Rulo cambia de Idle a Dormir tras un intervalo sin actividad. Si hay varias variantes Idle compatibles, cada clip termina y el motor elige la siguiente; con una sola, se mantiene en bucle. Las variantes se ponderan y se evita repetir clips recientes cuando hay alternativas.

Importar / registrar un clip

Se acepta MP4 o WebM de hasta 250 MB y cinco minutos. Las pose inicial/final deben describir el contenido real; el grafo solo puede atravesar poses con clips compatibles. Chroma es opcional y se aplica a la copia convertida. Para Hablar, usa la familia Hablar, comportamiento y las poses Idle_Base → Idle_Base; las respuestas reales inician el clip y el cartel espera ese primer fotograma, aplicando el delay de Rulo Dashboard.

Repetición y cooldown del clip seleccionado

Elige un clip para ver o modificar su bucle.

El bucle parcial repite desde el segundo inicial hasta el final indicado y después continúa el resto del clip. Si también está activo «Repetir el clip completo», el clip entero vuelve a empezar al terminar. El cooldown es el tiempo mínimo antes de que este clip vuelva a elegirse automáticamente. Los cambios de repetición se aplican la próxima vez que se reproduzca.
