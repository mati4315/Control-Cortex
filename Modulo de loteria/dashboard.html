☄️ Lotería Ball Control Panel

Configura, prueba y dispara la animación de la bolilla en OBS en tiempo real

🕹️ Modo de Operación

Modo de Prueba (Auto): La bolilla se lanza automáticamente en un bucle continuo con números aleatorios, usando los parámetros de abajo. Excelente para probar el diseño.

🚀 Guía de Inicio (Sync WS)

1) Abre una terminal en esta carpeta y ejecuta:

npm install
npm run start:ws

2) En este panel deja WebSocket URL en ws://localhost:688.

3) Abre lottery-ball.html (OBS, incógnito o navegador). Se sincroniza sola al conectar.

4) Verifica el badge: Sync WS activo (modo Manual/Test) o Online (modo Dynamic).

5) Si ves Sync WS offline, revisa que el servidor WS siga corriendo.
